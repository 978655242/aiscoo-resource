# Aiscoo 账户菜单暂时隐藏邀请好友

## 产品规则

- Aiscoo 登录用户的账户菜单暂时不展示「邀请好友 / Refer a friend」及奖励徽标；退出登录后也不展示。设置页与工作区复用同一账户菜单，桌面和 Web 均采用相同规则。
- 仅隐藏账户菜单项；Rewards Provider、奖励网页、营销活动下发的 rewards 导航及其登录续接继续使用原协议。账号信息、套餐、升级及登录/退出等其他菜单项不受影响。
- 共享菜单提供可选的展示策略，未注入时保持上游行为：已登录显示邀请项，未登录不显示。Aiscoo 产品入口固定注入隐藏策略，不依据登录渠道或异步状态切换。
- 这是一项静态 UI 装配策略，不拥有身份、奖励或会话状态；取消隐藏时可移除产品侧策略而保留共享默认行为。

## 验收

- 使用真实账户菜单组件及产品装配，在中文/英文、桌面/窄屏和明暗主题中验证已登录及退出后的菜单均不存在邀请项；账号信息及其他入口仍可使用。
- 未安装产品策略时，已登录菜单保留上游邀请项且可触发奖励动作，未登录菜单不出现该项。检查 DOM 是否存在，不能仅断言不可见。
- 产品配置下从独立奖励动作仍可打开奖励页；不把 fixture 当作真实服务端邀请或发奖验证。
- 产品包装同时应用于 Desktop、Web 与远控的共享 Root；保持上游正式 E2E 原样，使用独立 Aiscoo 浏览器验收覆盖产品策略。上游的菜单打开 E2E 在装配 Aiscoo 策略的产品运行中不再适用，待测试环境支持独立上游装配时再运行该上游用例。
